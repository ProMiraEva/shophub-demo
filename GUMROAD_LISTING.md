## Description

### What you get
ShopHub is a complete, production-ready online store template built as a single `index.html` file. No frameworks, no build tools, no servers required — just open it in a browser and start selling.

**Perfect for:**
- Digital product sellers
- Print-on-demand stores
- Dropshipping product catalogs
- Handmade craft shops
- Personal brand stores
- Side hustles and quick launches

### Features
✅ **Shopping cart** — add/remove items, quantity controls, persistent cart (localStorage)
✅ **Checkout form** — validated buyer details, order summary, copy-to-clipboard order
✅ **Category filters** — Electronics, Fashion, Home, Beauty, Sports
✅ **EN/BG language switcher** — built-in English and Bulgarian translations
✅ **Responsive design** — desktop, tablet, mobile
✅ **Dark/light mode** — automatic based on system preference
✅ **Fast and lightweight** — single HTML file, no dependencies
✅ **Easy customization** — edit products, prices, images in one place
✅ **Payhip integration ready** — direct "Buy Now" links per product

### How it works
1. Download the template
2. Edit the `PRODUCTS` array in `index.html` — replace with your products, images, prices, and Payhip links
3. Upload to any static host (Netlify, Vercel, GitHub Pages)
4. Start selling — no backend, no database, no monthly fees

### Customization
| What | Where to edit |
|------|---------------|
| Product name | `PRODUCTS[i].name` |
| Price | `PRODUCTS[i].price` |
| Image | `PRODUCTS[i].image` |
| Category | `PRODUCTS[i].category` |
| Payhip link | `PRODUCTS[i].payhip` |
| Store name | Change "ShopHub" in header |
| Colors | CSS variables in `:root` |
